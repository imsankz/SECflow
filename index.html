Usage

No config needed for basic scans.

secflow scan                  # → .secflow/report.md + .json
secflow scan --json           # machine-readable stdout
secflow scan --skip trivy     # skip missing engines
secflow scan --fail-on high   # severity gate
secflow report                # brief from last scan
secflow install-hook          # pre-commit gate
