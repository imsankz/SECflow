4 Scanning Engines

Each engine covers a different attack surface. Mix and match based on your install.

Engine What it scans Required?
gitleaks Committed secrets (800+ rule types) Recommended
trivy Dependency & container CVEs, extra secrets Optional
npm audit NPM dependency vulnerabilities Auto (skipped without package.json)
Custom regex Stripe, GitHub, OpenAI, AWS, Google, Slack, JWT, private keys, Supabase + your own rules Built in
📝

AI-Ready Fix Briefs

Reports include file:line locations, redacted matches, and severity-tagged fix instructions you paste directly into Claude Code, Cursor, or Codex.

⚡

Never Hard-Fails

Without gitleaks, SECflow still runs npm audit + its regex engine. Every engine is optional — a plain npx secflow scan never fails on a fresh machine.

🔄

CI / GitHub Actions

Ready-to-copy workflow. Exits non-zero on critical/high findings. Uploads .secflow/ artifact for team review.

🪝

Pre-commit Hook

secflow install-hook — runs gitleaks on staged files before every commit. Catches leaks before they hit the server.

Usage

Single-file CLI — no config needed for basic scans.

# Scan current directory → .secflow/report.md
secflow scan

# Machine-readable JSON on stdout
secflow scan --json

# Skip engines you don't have
secflow scan --skip trivy

# Fail on specific severities
secflow scan --fail-on high

# AI-ready brief from last scan
secflow report
